# Download haarcascade_frontalface_default.xml

Download the cascade classifier from OpenCV's GitHub repository:

**Source:** https://github.com/opencv/opencv/blob/master/data/haarcascades/haarcascade_frontalface_default.xml

**Steps:**
1. Click the "Download raw file" button on GitHub
2. Save it as `haarcascade_frontalface_default.xml` in this directory

**Or use this direct link:**
https://raw.githubusercontent.com/opencv/opencv/master/data/haarcascades/haarcascade_frontalface_default.xml

Once downloaded, the file will be used by the emotion detection scripts for face detection.
